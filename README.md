# MessageLab

MessageLab is an interactive messaging workbench built with React, TypeScript, Vite, and Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Run linting:
   ```bash
   npm run lint
   ```
